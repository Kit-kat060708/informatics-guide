# Информатика для первокурсника

## Цель проекта

Создание небольшого справочника по основам информатики.

## Автор

Екатерина

## Тема

Системы счисления

## Содержание проекта

* README.md - описание проекта
* glossary.md - словарь терминов
* examples.md - разобранные примеры
* sources.md - использованные источники
* questions.md - вопосы для самопроверки

## Как пользоваться справочником

Сначала изучить описание проекта, затем ознакомиться с терминами, разобрать примеры и пройти самопроверку.

## Порядок чтения

1. README.md - знакомство с проектом.
2. glossary.md - изучение основныых терминов.
3. examples.md - разбор примеров.
4. sources.md - изучение источников информации.
5. questions.md - самопроверка.

\## Рекомендации по работе

\* При изучении примеров из `examples.md` рекомендуется сначала прорешать задачи самостоятельно на черновике, а затем сверить ход решения.

\* Если встретился незнакомый термин, его определение можно быстро найти в `glossary.md`.
